# Activas A1.1 · 인터랙티브 학습 사이트

스페인어 교재 *Activas Curso de Español A1.1* (Unidad 1–5)의 연습문제를 온라인으로 풀고 채점하는 정적 사이트입니다.

- `index.html` 메인 · `unidad1~5.html` 단원 페이지
- `data/unitN.js` 문제/정답 · `data/audio-map.js` 듣기 파일 연결
- 점수는 학생 브라우저(localStorage)에만 저장됩니다.


`audio/`에 합성 음원이 들어 있습니다 (audio/README.md 참고).
